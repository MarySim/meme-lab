# Лабораторная работа: Интерактивный генератор мемов

**Дисциплина:** Современные средства и методы Web-разработки

**Выполнила:** Симонова Марина, группы ФИТ-241  

## Описание проекта
SPA-приложение (Single Page Application) для генерации пользовательских мемов на основе шаблона «Маомао (Монолог фармацевта)». Приложение позволяет динамически подставлять текст в заранее определенные области изображения, используя клиентский рендеринг через Canvas API. 

Логика приложения полностью отделена от контента: структура текста, координаты и настройки шрифтов вынесены в отдельный конфигурационный файл `data.json`.

## Функционал
1. **Динамический рендеринг:** Генерация текста поверх изображения в реальном времени с автоматическим расчетом переноса строк.
2. **Архитектура Data-Driven:** Текстовые шаблоны и ключи (`{awesome_thing}`, `{crazy_idea}` и т.д.) подгружаются из `data.json`, что позволяет легко масштабировать проект или заменять шаблоны мемов без изменения JS-кода.
3. **Бесшовная навигация (SPA):** Плавный переход от формы редактирования к результату с расширением интерфейса.
4. **Экспорт:** Возможность скачивания сгенерированного холста в формате `.png` средствами браузера.
