# meme-lab
=======
# Сборник проектов по Web-разработке

Данный репозиторий представляет собой единый портал для лабораторных работ. Проект включает удобное навигационное меню для быстрого доступа к каждому заданию.

**Выполнила:** Симонова Марина, группы ФИТ-241.

## Структура репозитория

Проект имеет модульную структуру. Корень содержит главное меню (хаб), а сами приложения изолированы в отдельных директориях:

### 1. Генератор мемов (`/meme/`)
**Лабораторная работа №1.**  
Динамический веб-интерфейс для генерации и кастомизации мемов.
* **Технологический стек:** HTML5, CSS3, JavaScript, jQuery.
* **Ключевые особенности:**
  - Данные подгружаются асинхронно из локального файла `data.json`.
  - Динамическое обновление DOM-дерева через jQuery.
  - Интерактивная панель выбора шаблонов.

### 2. Жуткий урожай (`/halloween/`)
**Дополнительное задание (Хэллоуинский проект).**  
Браузерная мини-игра в жанре «Тамагочи» с элементами тайм-менеджмента и выживания.
* **Технологический стек:** HTML5, CSS3, Vanilla JavaScript (без сторонних библиотек).
* **Ключевые особенности:**
  - **Игровая механика:** Контроль трех параметров (влага, свет, грунт) для выращивания Тыквы-мутанта.
  - **Динамическая сложность:** Множитель расхода ресурсов увеличивается (от x2 до x5.5) с каждой новой стадией роста.
  - **Система паузы и UI:** Возможность остановить игровой цикл (`setInterval`) с вызовом оверлея правил игры.
  - **Режим разработчика:** Встроенная функция (чит-код) для мгновенного пропуска геймплея и демонстрации финальной стадии.
  - **CSS-анимации и эффекты:** Реализован всплывающий текст (Floating Combat Text) по координатам курсора, эффект дрожания экрана (Screen Shake) при критическом уровне шкал, вспышки молний и фоновые атмосферные анимации.
